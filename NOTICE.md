# Third-party code and models

Bundled:

- **Mona Sans** (GitHub, SIL Open Font License 1.1): the product typeface, in `docs/design/fonts/`, copied unchanged. The web app bundles and serves this same file. Licence: `docs/design/fonts/LICENSE-mona-sans.txt`.

Installed, not copied:

- **Tiptap 3.32.0** (MIT): the recap editor, installed from npm, open packages only: `@tiptap/core`, `@tiptap/react`, `@tiptap/pm`, `@tiptap/starter-kit`, `@tiptap/extension-heading`, `@tiptap/extension-list` (task lists), `@tiptap/extension-table`, `@tiptap/extension-image`, `@tiptap/extension-mention`, `@tiptap/suggestion`, `@tiptap/extension-details`, `@tiptap/extension-text-style`, `@tiptap/extensions` (placeholder), `@tiptap/extension-drag-handle` and `@tiptap/extension-drag-handle-react` with their peers `@tiptap/extension-node-range`, `@tiptap/extension-collaboration`, `@tiptap/y-tiptap`, `yjs` and `y-protocols` (MIT). No Tiptap Pro package, no Tiptap cloud, no Tiptap template: the editor is built from `docs/design`. Markdown in and out with `prosemirror-markdown` 1.13 and `markdown-it` 14 (MIT); the Word export with `docx` 9.13 (MIT), which brings `jszip` (MIT or GPL-3.0, used under MIT) and `pako` (MIT and Zlib, a named exception).
- JavaScript dependencies come from npm under their own licences: MIT, Apache-2.0, BSD, ISC, and the packages named in `scripts/license-exceptions.json`. `pnpm check:licenses` lists them and fails on anything else. The shadcn/ui components in `apps/web/components/ui` are generated by the shadcn CLI (MIT) and edited here.

Models the library calls:

- **Whisper large-v3-turbo** (OpenAI, MIT), run by Cloudflare Workers AI as `@cf/openai/whisper-large-v3-turbo` when an install picks Workers AI Whisper. Called through the `AI` binding under the installing company's Cloudflare account; no weights are in this repository.
- **Llama 4 Scout 17B 16E Instruct** (Meta, Llama 4 Community License), run by Cloudflare Workers AI as `@cf/meta/llama-4-scout-17b-16e-instruct`, the default recap model. Called through the `AI` binding under the installing company's own Cloudflare account and its terms; no weights are in this repository. "Built with Llama." An install can pick Anthropic, OpenAI or Azure OpenAI instead, under its own agreement.

Planned, to be recorded here when they land:

- Rust crates the recorder will depend on (cpal, whisper-rs, ONNX runtime bindings, Tauri plugins), each under MIT or Apache-2.0, listed here when added. Vibe, anarlog and Meetily are read as references; no code from them is in this repository.
- **Parakeet TDT 0.6B v3** (NVIDIA, CC-BY-4.0): local speech-to-text model, downloaded by the recorder on first run. Attribution: "Parakeet TDT 0.6B v3 by NVIDIA, licensed under CC-BY-4.0."
- **Whisper large-v3-turbo** (OpenAI, MIT): fallback local model in the recorder.

Speech-to-text and language-model providers are called over their APIs under the installing company's own agreement with them. None of their code is in this repository.
